"unhackable."
Messages are encrypted at rest and in transit
(TLS + Supabase encryption-at-rest)
Every table has Row Level Security (RLS); no
sensitive operation may rely on frontend-only
checks
Message content is queryable server-side, which
is what enables message search, mention

3. ACCOUNT SYSTEM
Users create accounts with: username, display name,
email, password, profile picture, optional bio.
Every account automatically receives a unique 6-digit
Friend Code (e.g. 482731 ):
Exactly 6 digits, unique, immutable by the user
(admin can reset it)
Never used as authentication — it is a discovery
identifier only
Never expose internal database IDs publicly
Rate-limit Friend Code lookups server-side to
prevent enumeration/abuse
Searching a code shows: display name, @username,
profile picture, bio (respecting privacy settings) —
then the searcher can send a friend request.
